## 📝 Descrição do projeto
O **Revela** é uma aplicação web para organizar o amigo secreto de forma simples e segura. O organizador cria um grupo, compartilha um convite e realiza o sorteio automaticamente, sem papeizinhos e sem risco de alguém tirar a si mesmo. Cada participante vê apenas o próprio resultado e a lista de desejos de quem tirou.
